# Designs for queued improvements

One file per item in IMPROVEMENTS.md (`Q-NNN.md`), drafted by the nightly improvement pass
(`ops/tasks/nightly-improvement-pass.md`) before Michael decides. A design names the files it would change, how it would be
tested out of sample, which `docs/data/health.json` checks should move, the risks and the rollback. Nothing here is built
until the item's Decision says approved.
